# JX Discord API

A lightweight, server-side Discord API integration for FiveM. It provides exports that other scripts can use to look up player Discord data including roles, usernames, and avatars.

<Note>
  **Free & Open Source** - Fully open source, including all core logic in `server/server.lua`.
</Note>

## Key Features

- Discord role verification for players
- Avatar and username lookup via Discord API
- Connection logging via Discord webhooks
- Player data caching with configurable timeout
- Built-in rate limiting to avoid Discord API abuse
- Optional guild membership enforcement (kick players not in your Discord)

---

## How It Works

This is a **server-side only** resource — there are no client scripts. It runs entirely on the server, making HTTP requests to the Discord API to fetch player data.

When a player connects, the script:

<Steps>
  <Step title="Identify Player">
    Reads the player's Discord identifier from their FiveM account
  </Step>
  <Step title="Fetch Discord Data">
    Queries the Discord API for their user info and guild membership
  </Step>
  <Step title="Cache Results">
    Stores the data in memory so future lookups are instant
  </Step>
  <Step title="Provide Exports">
    Other scripts can call exports to get roles, avatars, usernames, and more
  </Step>
</Steps>
