# JX Spawn Selector

A modern spawn location selector for FiveM with a map-based NUI interface. Players choose where to spawn after logging in with their character.

<Note>
  **Free & Open Source** - Completely free to use and modify for your server.
</Note>

## What It Does

JX Spawn Selector provides a clean UI for players to pick their spawn location:

- **Map-Based Interface** — Interactive map with clickable location pins
- **Last Location Support** — Players can return to where they last logged out
- **Multiple Spawn Points** — 5 default locations, easily expandable
- **Modern NUI** — Sleek design with customizable theme colors
- **Framework Support** — Works with ESX, QBCore, and Qbox (auto-detection)

## Compatibility

Works seamlessly with **jx_multicharacter** — the spawn selector automatically appears after character selection.

Also compatible with other multicharacter systems through the server-side export:

```lua
-- Trigger the spawn selector for a player from any resource
exports.jx_spawnselector:RequestSpawnSelector(source)
```

## File Structure

<CodeGroup>

```bash Resource Structure
jx_spawnselector/
├── config/
│   ├── config.lua       ← Main settings
│   └── spawn.lua        ← Spawn locations
├── locales/
│   ├── en.lua           ← English translations
│   └── es.lua           ← Spanish translations
├── client/              ← Client scripts (escrowed)
├── server/              ← Server scripts (escrowed)
├── bridge/              ← Framework bridge (escrowed)
├── utils/               ← Utilities (escrowed)
├── web/dist/            ← NUI interface
└── fxmanifest.lua
```

</CodeGroup>

<Info>
  **Editable files**: Everything in `config/` and `locales/` can be freely modified. Client, server, bridge, and utils scripts are escrowed.
</Info>
