# Configuration

Customize every aspect of the VIP System through `shared/config.lua` — features, prices, cooldowns, shop items, travel locations, and Discord roles.

<Info>
  All configuration is in `shared/config.lua`. Restart the resource after making changes: `restart jx_vip`
</Info>

---

## Configuration File

```bash
jx_vip/
├── shared/
│   ├── config.lua       ← Main configuration
│   └── framework.lua    ← Framework overrides
├── client/
│   ├── features.lua     ← Client feature logic
│   └── menu.lua         ← Menu rendering
└── server/
    ├── cooldowns.lua    ← Cooldown system
    └── features.lua     ← Server feature logic
```

## Framework Settings

### Config.Framework

<ParamField path="Config.Framework" type="string" default="'auto'">
  Framework detection mode. Auto-detects ESX, QBCore, or Qbox.
</ParamField>

```lua shared/config.lua
Config.Framework = 'auto' -- 'auto', 'esx', 'qbcore', 'qbox', 'standalone'
```

---

### Config.SkinMenu

<ParamField path="Config.SkinMenu" type="string" default="'auto'">
  Skin/clothing menu used for the clothing feature. Auto-detects the installed system.
</ParamField>

```lua shared/config.lua
Config.SkinMenu = 'auto'
```

**Supported Menus** (detection order):
- illenium-appearance
- qb-clothing
- esx_skin
- skinchanger
- fivem-appearance
- codem-appearance
- ag_appearance

<Tip>
  Leave as `'auto'` unless auto-detection fails. Set to the exact resource name to force a specific menu.
</Tip>

## Discord Configuration

### Config.Discord

Configure which Discord roles grant VIP access. Requires JX Discord API.

```lua shared/config.lua
Config.Discord = {
    vipRoles = {
        '123456789012345678', -- VIP role ID
        '987654321098765432'  -- VIP+ role ID
    }
}
```

<Steps>
  <Step title="Get Role IDs">
    Enable Developer Mode in Discord → Right-click roles → Copy ID
  </Step>
  <Step title="Add to Config">
    Paste role IDs into the `vipRoles` array
  </Step>
  <Step title="Order Matters">
    First role = VIP, Second role = VIP+
  </Step>
</Steps>

<Warning>
  If you only have one VIP tier, use the same role ID for both entries.
</Warning>

## Menu Configuration

### Config.Menu

Customize the VIP menu appearance and keybind.

```lua shared/config.lua
Config.Menu = {
    title = 'VIP Menu',
    subtitle = 'Exclusive features for VIP members',
    position = 'top-right',  -- 'top-right', 'top-left', 'center'
    keybind = {
        name = 'vip_menu',
        key = 'F5',
        description = 'Open VIP Menu'
    }
}
```

**Position Options**: `'top-right'`, `'top-left'`, `'center'`

**Common Keybinds**: `F5`, `F6`, `F7`, `HOME`, `INSERT`

<Tip>
  If F5 conflicts with another resource, change it here. Players can also remap it in FiveM keybind settings.
</Tip>

## Features Configuration

### Config.Features

Customize each VIP feature's availability, price, cooldown, required tier, and display info.

### Feature Structure

```lua
feature_name = {
    enabled = true,           -- Enable/disable the feature
    price = 500,              -- Cost to use (in-game money)
    cooldown = 300,           -- Cooldown in seconds
    vipLevel = 'vip',         -- Required tier: 'vip' or 'vip_plus'
    title = 'Feature Name',   -- Display name in menu
    description = 'Text',     -- Description shown in menu
    icon = 'heart'            -- Font Awesome icon name
}
```

</Tip>

## VIP Shop Configuration

### Config.Shop

Configure the exclusive VIP item shop with tiered pricing.

```lua shared/config.lua
Config.Shop = {
    enabled = true,
    title = 'VIP Shop',
    subtitle = 'Exclusive items for VIP members',
    currency = 'money',  -- 'money', 'bank', 'black_money'
    items = {
        vip = {
            -- Items for VIP tier
        },
        vip_plus = {
            -- Items for VIP+ tier (better prices + exclusives)
        }
    }
}
```

### Shop Items

<Tabs>
  <Tab title="VIP Items" icon="star">
    Items available to VIP members:

    ```lua shared/config.lua
    vip = {
        {name = 'bread',   label = 'Bread',   price = 25,  count = 5, icon = 'bread-slice'},
        {name = 'water',   label = 'Water',    price = 15,  count = 3, icon = 'tint'},
        {name = 'bandage', label = 'Bandage',  price = 150, count = 2, icon = 'band-aid'}
    }
    ```
  </Tab>

  <Tab title="VIP+ Items" icon="crown">
    VIP+ members get better prices and exclusive items:

    ```lua shared/config.lua
    vip_plus = {
        -- Discounted versions of VIP items
        {name = 'bread',     label = 'Bread (Discount)',        price = 12,  count = 10, icon = 'bread-slice'},
        {name = 'water',     label = 'Water (Discount)',        price = 8,   count = 5,  icon = 'tint'},

        -- VIP+ exclusive items
        {name = 'lockpick',  label = 'Lockpick (Exclusive)',    price = 500, count = 3,  vipLevel = 'vip_plus', icon = 'key'},
        {name = 'repairkit', label = 'Repair Kit (Exclusive)',  price = 750, count = 1,  vipLevel = 'vip_plus', icon = 'tools'}
    }
    ```
  </Tab>
</Tabs>

### Item Properties

| Property | Type | Required | Description |
|----------|------|----------|-------------|
| `name` | string | Yes | Item spawn name (must exist in your inventory) |
| `label` | string | Yes | Display name in the shop |
| `price` | number | Yes | Purchase cost |
| `count` | number | Yes | Quantity received per purchase |
| `icon` | string | Yes | Font Awesome icon name |
| `vipLevel` | string | No | Restrict to a specific tier (`'vip_plus'`) |

<Warning>
  Make sure all item `name` values exist in your framework's inventory system. Items that don't exist will fail to give.
</Warning>

## Quick Travel Configuration

### Config.QuickTravel

Set up teleport locations for VIP+ members.

```lua shared/config.lua
Config.QuickTravel = {
    enabled = true,
    vipLevel = 'vip_plus',  -- Required VIP tier
    locations = {
        {name = 'Hospital',  coords = vector3(295.87, -1446.94, 29.97),   price = 200},
        {name = 'City Hall', coords = vector3(-544.85, -204.13, 38.22),   price = 200},
        {name = 'Airport',   coords = vector3(-1037.17, -2737.73, 20.17), price = 300},
        {name = 'Beach',     coords = vector3(-1393.84, -1020.32, 7.68),  price = 250}
    }
}
```

### Adding Locations

<Steps>
  <Step title="Get Coordinates">
    Stand at the desired location in-game and run a coord command (e.g., `/getcoords`)
  </Step>
  <Step title="Add to Config">
    ```lua
    {name = 'Location Name', coords = vector3(x, y, z), price = 200}
    ```
  </Step>
  <Step title="Set Pricing">
    Adjust price based on how desirable the location is. Popular spots can cost more.
  </Step>
</Steps>

<Tip>
  Keep travel prices balanced with your economy. Too-cheap travel can make vehicles and taxis irrelevant.
</Tip>

## Editable Files

Beyond `shared/config.lua`, you can customize behavior in these files:

<AccordionGroup>
  <Accordion title="shared/framework.lua" icon="server">
    Override framework detection or add custom framework support.
  </Accordion>

  <Accordion title="client/features.lua" icon="display">
    Customize client-side feature behavior (e.g., how heal, armor, or clothing menu works).
  </Accordion>

  <Accordion title="client/menu.lua" icon="bars">
    Customize the ox_lib menu rendering and layout.
  </Accordion>

  <Accordion title="server/cooldowns.lua" icon="clock">
    Modify the cooldown system behavior (e.g., persistent cooldowns, cooldown bypass).
  </Accordion>

  <Accordion title="server/features.lua" icon="server">
    Customize server-side feature logic (e.g., how money is deducted, items are given).
  </Accordion>
</AccordionGroup>

<Warning>
  `server/discord.lua`, `server/main.lua`, and `server/version.lua` are **escrowed** and cannot be edited.
</Warning>

## Testing Your Configuration

<Steps>
  <Step title="Save Config">
    Save `shared/config.lua`
  </Step>
  <Step title="Restart Resource">
    Run `restart jx_vip` in server console
  </Step>
  <Step title="Test Features">
    Join server, press F5, test each feature
  </Step>
  <Step title="Adjust">
    Fine-tune prices and cooldowns based on player feedback
  </Step>
</Steps>

<Tip>
  Start with higher prices and lower them based on player feedback. It's easier to reduce prices than increase them.
</Tip>
