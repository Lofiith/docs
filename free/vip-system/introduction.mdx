# VIP System

A comprehensive VIP perks system that uses Discord roles to grant exclusive in-game features, a tiered item shop, and quick travel — all managed through a clean ox_lib menu.

<Note>
  **Free Resource** - Works with ESX, QBCore, and Qbox via auto-detection.
</Note>

## What It Does

Turn Discord roles into real in-game advantages:

- **Two VIP Tiers** — Regular VIP and VIP+ with different perks and pricing
- **Instant Features** — Heal, armor, vehicle repair, vehicle wash, clothing menu
- **VIP+ Exclusives** — God mode, invisibility, and quick travel
- **VIP Shop** — Tiered item shop with different prices and items per tier
- **Quick Travel** — Teleport to preset locations for a price (VIP+ only)
- **Smart Cooldowns** — Prevent feature spam with configurable cooldown timers
- **Discord Verification** — Automatic role checking via JX Discord API

## How It Works

<Steps>
  <Step title="Install Dependencies">
    Install ox_lib and JX Discord API
  </Step>
  <Step title="Configure Discord Roles">
    Set your VIP and VIP+ Discord role IDs in the config
  </Step>
  <Step title="Customize Features">
    Adjust prices, cooldowns, shop items, and travel locations
  </Step>
  <Step title="Players Get Access">
    Players with VIP Discord roles press F5 or type `/vipmenu` to access perks
  </Step>
</Steps>
